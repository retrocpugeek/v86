Buildroot arm64 Linux running on v86's AArch64 core (ARMv8.0, QEMU virt-like machine), entirely in your browser. Log in as root (OpenWrt: press Enter once the console is ready; LuCI, the web interface, appears next to the console once it's up: user root, empty password). Disk changes stay in this tab. Networking: plain HTTP (wget http://…), proxied through this site; HTTPS from the guest isn't supported (?relay=wisps://… selects a full network relay). Source · All the v86 ports
