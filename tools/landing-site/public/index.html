A fork of v86

Linux on ARM64 and RISC-V,
in your browser

v86 emulates an x86 PC in WebAssembly. This fork adds two more machines to it: a 64-bit ARM (AArch64) computer and a RISC-V computer (64- and 32-bit), each booting real Linux images built with Buildroot, with a serial console, a virtual disk and networking, entirely client-side.

Pick a machine

ARM64 (AArch64)

An ARMv8-A CPU with a QEMU virt-like machine: GIC interrupt controller, PL011 UART, virtio disk, network and input devices, and a framebuffer.

  • Buildroot Linux (ext4 and squashfs)
  • OpenWrt 24.10 with the LuCI web interface
  • U-Boot booting Linux from the disk
  • X11 desktop: openbox, xterm, on-screen keyboard
  • JIT: hot code compiled to WebAssembly
  • gdb-wui: debug programs in the guest from a web UI next to the console

RISC-V (RV64GC and RV32GC)

A RISC-V hart with machine, supervisor and user modes, Sv39 and Sv32 paging, CLINT, PLIC, 16550 UART and virtio devices, started by OpenSBI.

  • Buildroot Linux, riscv64 and riscv32
  • Passes the riscv-tests ISA suites (rv64 and rv32)
  • Checked instruction by instruction against QEMU
  • JIT: hot code compiled to WebAssembly
  • A WCH CH32V003 microcontroller (RV32EC, 2 KB of RAM) running a bare-metal Tetris, with touch controls for phones
  • gdb-wui: debug programs in the guest from a web UI next to the console
  • Stefan Wagner's CH32V003 Mini Game Console: its OLED display, buttons and buzzer, with six games (Tris, Invaders, Arkanoid, Pacman, Lander, Life)
  • A WCH CH32V307 microcontroller (RV32IMAFC, 64 KB of RAM) running the RT-Thread shell, with snake, an analog clock, CoreMark and Lua

x86 (the original)

The original v86 by its upstream authors: a 32-bit x86 PC that runs Linux, Windows, BSDs, DOS and more, with its own JIT. This fork doesn't change it.

  • Many ready-made operating systems
  • VGA graphics, sound, networking

Debugging in the browser: gdb-wui

gdb-wui is a web UI for GDB: source, disassembly, variables, registers, memory, threads and a gdb console in one window, with gdb itself doing the debugging. On both sites an image runs it inside the emulated machine, next to the console: gdb and gdb-wui run in the guest, and the page carries gdb-wui's HTTP and WebSocket traffic over v86's virtual network, so nothing leaves your browser.

Its example programs are in /root/demo: pick one, click Run→main and step. Or start gdbserver :1234 /root/demo/hello & on the console and click connect in gdb-wui's console bar to debug it remotely.

Built with Claude

The ARM64 and RISC-V ports were done entirely using Claude Opus 5.5, Anthropic's model, working in Claude Code: the CPU cores and their JIT compilers (in Rust, compiled to WebAssembly), the device models, the test harnesses that run the cores in lockstep with QEMU, the scripts that build the OpenWrt, U-Boot and X11 images, and these sites.

The original v86 and its x86 emulation are the work of the upstream project's authors.
